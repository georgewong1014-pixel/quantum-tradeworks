# Phase 2 — Equities Research Consolidation, against the application as it stands

*Written 27 September 2026 against commit 903afee, from an audit of every EQ item
in the "Phase 2 Development Instructions" brief by eight independent readers of
the code. Each item records what the application already does (with file and
line), what the brief asks for that is not there, what can be built now, and
what is blocked and on what.*

## 0. The decision this plan rests on

The brief describes a server product: a database with an `Instrument` table,
`/api/v1/*` routes with authorisation, user accounts that own watchlists,
server-generated PDF reports, database migrations with rollback. The decision
recorded in [platform-plan.md](platform-plan.md) on 27 September stands: the
current application — one static file, browser storage, no accounts, no
licensed prices — is the product and is extended; the server layer is a later
phase gated on an operating entity, a licensed end-of-day feed with
redistribution rights, and written Malaysian legal classification. Every item
below is therefore read twice: once as the brief wrote it, and once as the
nearest thing a static application can honestly deliver.

Three facts recur in the blocked columns and are stated once here:

1. **`data/us.json` has not been regenerated** since the ingest gained the
   year-end rule and per-line provenance (period ends, filing dates, forms).
   SEC EDGAR returns 403 without an email-shaped contact in the User-Agent,
   and no contact address has been supplied. Everything that says "needs
   regeneration" waits on that one string. See [platform-plan.md §12.2](platform-plan.md).
2. **The statement tuple is ten columns wide** (revenue, EBIT, net income,
   operating cash flow, capex, equity, debt, cash, shares, dividend per
   share). Gross margin, return on assets, current and quick ratios, interest
   cover and EV/EBITDA need lines that are not in it. Widening it is a code
   change of modest size that only takes effect with the regeneration above.
3. **No Bursa Malaysia financial source is licensed.** The Malaysian set is
   synthetic and labelled so on every page; nothing in this phase promotes it.
