**Duplicate tools or competing stores of truth:** none for customer data (one localStorage store, one export format). The report draft (browser) and the submitted record (GitHub) are two records by design, distinguished by status and receipt. The capability register (`80-registers.js`) and the product list (`35-ui.js`) use different status vocabularies; both are rendered from code, neither is a second store.

**Tools visible in the interface but backed only by local storage, mock data or unconfigured services:** every "My …" tool is browser-local by design and says so; the Submit control appears only when `/api/report` answers `configured: true`; the plan buttons preview locally and say "nothing is charged"; the Kuching map and NAPIC cards read shipped files. No placeholder API is called.

**Hidden or legacy:** `/admin/scanner*` (unauthenticated, empty on the host, disallowed in robots.txt); route aliases (`/wheel`, `/cash-wheel`, `/app/equities/*`); the QTTI batch tools (operator only).
