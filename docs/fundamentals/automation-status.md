# Automation status

What runs by itself, what runs on someone's machine, and what is manual, as the repository shows it. "Yes" means the repository defines the trigger and the step runs with no person. "Partly" means part of the step is automatic. "No" means a person runs it. Whether something is currently switched on in an account or on a machine that the repository cannot see is marked `UNKNOWN - George to confirm [Qn]` (see open-questions.md).
