# Quantum Tradeworks
#
# /my/ holds one reader's own portfolios, investment cases, watchlists, property
# evidence and correction cases. None of it leaves the browser, so there is
# nothing there for a crawler to fetch — but a personal surface should not be in
# an index whatever it happens to contain today. /app/watchlists is the Phase 2
# brief's address for the same watchlists page, so it is excluded with it, and
# /app/workspace — everything saved in this browser — with /my/workspace.
#
# /app/scanner is the personal-lane scanner: the reader's own setups, alerts
# and history, read from files on their own machine. /admin/ is a read-only
# view of one machine's scanner worker. Neither has anything for an index.
#
# /app itself is My Dashboard since Release A: the visitor's own counts and
# saved work, read from their browser. Only that address — "$" ends the match,
# which Google and Bing honour — so the product pages under /app stay as they
# were. The sitemap already leaves it out.

User-agent: *
Disallow: /app$
Disallow: /my/
Disallow: /app/watchlists
Disallow: /app/workspace
Disallow: /app/scanner
Disallow: /admin/
Allow: /
