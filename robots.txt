# Quantum Tradeworks
#
# /my/ holds one reader's own portfolios, investment cases, watchlists, property
# evidence and correction cases. None of it leaves the browser, so there is
# nothing there for a crawler to fetch — but a personal surface should not be in
# an index whatever it happens to contain today. /app/watchlists is the Phase 2
# brief's address for the same watchlists page, so it is excluded with it, and
# /app/workspace — everything saved in this browser — with /my/workspace.
#
# /property/models is My properties: the properties one reader saved, read from
# their browser. Personal, like /my/.
#
# /admin/ is a read-only view of one machine's scanner worker. Nothing there
# is for an index.
#
# /app (My Dashboard) and /app/scanner with every address under it (the
# scanner's dashboard, the setup builder, setups and alerts) are NOT
# disallowed here (plan item 1.1, the owner's decision D2 of 5 Oct 2026). A
# fetcher that follows this file could not read them at all — an assistant or
# an auditor asked about the Scanner was turned away from /app/scanner and
# /app/scanner/setups/new — although what each serves is a fresh visitor's
# page, with nothing of any reader's in it. They are kept out of search
# instead by an X-Robots-Tag: noindex response header (vercel.json): a page
# must be fetchable for a search engine to read that it may not be indexed.
# The sitemap leaves them out.
#
# /prerender/ holds each page's content as build.mjs puts it into that page
# (prerender.mjs): served at its own address, it is a copy of a page with no
# head of its own. The page itself is the one to index.

User-agent: *
Disallow: /my/
Disallow: /app/watchlists
Disallow: /app/workspace
Disallow: /property/models
Disallow: /admin/
Disallow: /prerender/
Allow: /
